# Rogue Zork React - Agent Notes

## Development

- **Dev Server**: Run `npm run dev` - runs on port **4173**
- **Build**: `npm run build`

## UI Layout

- Collapsible bottom panel with d-pad, quick actions
- Full-screen popup menus for actions and settings
- Quick panel: Look, Talk, Take All, Inventory, Health, Map, Quests, Save, More

## Settings

- Theme toggle (dark/light)
- Text size slider (12-20px)

## Game Features

- First visit shows full room description
- Revisits show brief "(You've been here)" message
- Take All button grabs all items in room
- Talk button shows character selection if multiple NPCs

- Added settings popup with theme/text size controls
- Added stats display in action popup header
- Added take-all and talk buttons to quick panel
